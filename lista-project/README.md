# Exercícios de Fundamentos em Java

Coleção de listas de exercícios para fixação dos conceitos básicos e sintaxe do Java, cobrindo estruturas sequenciais, condicionais e de repetição.

## Conteúdo do Projeto

- **Lista01.java (Estrutura Sequencial)**
         Operações matemáticas básicas, cálculo de áreas geométricas (fórmula do raio, trapézio, etc.), cálculo de salários, preços e formatação de saída com `Scanner` e `Locale`.

- **Lista02.java (Estrutura Condicional)**
         Estruturas `if / else` e `switch-case`. Exercícios envolvendo verificação de ímpares/pares, múltiplos, contagem de horas de jogo, quadrantes e cálculo de faixas do Imposto de Renda.

- **Lista03_1.java, Lista03_2.java e Lista03_3.java (Estrutura Repetitiva - While)**
         Laços de repetição com condição no início. Resolução de problemas como validação de senha, verificação contínua de coordenadas e menu de pesquisa de combustível.

- **Lista04.java (Estrutura Repetitiva - For)**
         Laços com número definido de repetições. Exercícios de contagem, verificação de intervalos (in/out), média ponderada, divisões, fatorial e cálculo de potências (quadrado e cubo).
