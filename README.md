# Curso Java - Exercícios & Aprendizado

Este repositório contém todos os códigos e exercícios desenvolvidos ao longo do meu curso de Java, cobrindo desde a lógica de programação até a Programação Orientada a Objetos (POO).

---

## Estrutura do Repositório

O repositório é estruturado em um projeto Java (`listas`), onde os exercícios são organizados em pacotes dentro do diretório `src/`:

```text
curso-java/                        # Pasta raiz do Repositório Git
└── listas/                        # Projeto Java
    ├── src/
    │   ├── fundamentos/           # Lógica de programação e estruturas de controle
    │   │   ├── lista01/          # Estrutura Sequencial
    │   │   ├── lista02/          # Estrutura Condicional (if / else)
    │   │   ├── lista03/          # Estrutura Repetitiva (while)
    │   │   └── lista04/          # Estrutura Repetitiva (for)
    │   │
    │   └── poo/                   # Programação Orientada a Objetos (Em breve)
    │       ├── introducao/       # Classes, atributos e métodos
    │       ├── construtores/     # Encapsulamento e sobrecarga
    │       └── heranca/          # Herança e Polimorfismo
    │
    └── README.md
