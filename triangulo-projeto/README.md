# Exercício Triângulo (POO vs Estruturado)

Exercício prático comparando o cálculo da área de dois triângulos com e sem o uso de Orientação a Objetos.

## O que tem no projeto

- `SemPOO.java`: Resolução inicial usando lógica estruturada direto na `main`.
- `Triangulo.java`: Classe que representa o triângulo com seus atributos e o método `area()` (fórmula de Heron).
- `TringuloApplication.java`: Classe principal instanciando os objetos e comparando os resultados.
